Tik Manager 4 - trigger3 (tik.trigger workflow v3)

1. Put tikworks on PYTHONPATH:  D:/dev/tikworks/src/python
2. Put this folder's plugins on TRIGGER_PLUGIN_PATH:
       <tik_manager4>/tik_manager4/dcc/trigger3/plugins
   or call tik.trigger.add_plugin_path(<that folder>) from userSetup.py before
   opening Trigger. Trigger then shows a "Tik Manager" submenu under File, a
   Tik Manager button on every file field, and a tik_publish action.
3. tik_publish always publishes its three elements (source, guides, rig)
   whatever the category lists; listing them in the category only matters
   for publishes driven from Tik Manager's own Publish dialog, where the
   order must be source, guides, rig -- because the rig extractor builds,
   and a build deletes the guide joints.
4. Works of this DCC are .tr files; a publish is a SOURCE_ bundle folder, a
   rig .mb and a guides .trg, with shared dependencies under _store/.
5. Open published sessions read-only: loading one as a new work version is
   a tik_manager4 limitation, because Publish.load_version iterates the work
   with new_version(file_format="") -- the bundle folder has no extension --
   and the new version gets no usable session file.
